❹ 数据模型

技术

DiaryEntry 已有 fontName、fontSize、fontColorHex 字段，本次只需加 lineSpacing（Double，默认 1.6）。

@Model final class DiaryEntry {
  // … existing fields …
  var fontName: String = "System"
  var fontSize: Double = 17
  var fontColorHex: String = ""
  var lineSpacing: Double = 1.6  // ← 新增
}

❺ 与设置页的关系

默认值

设置页「写日记偏好」中的默认字体和默认字号，控制新建日记时字体面板的初始选中值。用户在任何一篇日记里改了字体，不影响默认值，也不影响其他日记。
