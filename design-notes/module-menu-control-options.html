模块菜单 · 显隐控件选型

替代 Toggle 开关的三个候选。整行可点（点哪都行），控件只负责表达状态。菜单语义 = "这个模块显示与否"，对照系统惯例选控件。

A

对勾 ✓

推荐
macOS 菜单栏 / iOS Menu 的标准"显示-隐藏"语义（访达「显示」菜单、SwiftUI Menu 的勾选项都是它）。 显示 = 尾部一个 accent 对勾；隐藏 = 对勾消失、整行变淡。无控件边框，视觉上最"轻"，和纸质调性最搭。

B

眼睛 👁

图层显隐的行业符号（Figma / PS 图层面板）。语义最直白："睁眼 = 显示，闭眼 = 隐藏"。 缺点是你之前提过的——眼睛图标视觉噪音略重，且隐藏态的斜杠眼在小尺寸下偏糊。
